# Validate your inputs

Create valid inputs and handle an invalid script without a panic.

## Before you start

No API key or network connection is needed. You need Rust 1.98.0.

## Run from the source checkout

```sh
cargo run --example validate_inputs
```

The [complete source](https://docs.rs/crate/daytona-rs/0.2.1/source/examples/validate_inputs.rs)
is shipped with the crate and included below.
