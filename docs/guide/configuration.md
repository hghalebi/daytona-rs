# Configure a client

Supply credentials explicitly and choose a request deadline.

## Before you start

Read the [input lesson](crate::guide::inputs). This example only constructs a client.
It sends no API request, so a synthetic key is sufficient for this local lesson.

## Run from the source checkout

```sh
DAYTONA_API_KEY=documentation-example cargo run --example configure_client
```

The [complete source](https://docs.rs/crate/daytona-rs/0.2.1/source/examples/configure_client.rs)
is shipped with the crate and included below.
